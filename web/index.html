natlas-kit is a Python & TypeScript SDK and CLI for NCAIR's N-ATLaS language and speech models. Unified backends, reliable structured output, Nigerian-language tasks, speech-to-text and an eval harness, in the language you already use.

The gap

N-ATLaS is powerful. Building on it isn't.

Every team re-solves the same four problems before writing a single line of their product. natlas-kit solves them once, for everyone.

1

No hosted API

You self-host. natlas-kit speaks TGI, vLLM/OpenAI-compatible and a mock backend out of the box.

2

Tricky templating

N-ATLaS uses a dated Llama-3 chat header that's easy to get wrong. natlas-kit builds it for you.

3

No structured output

Chat models don't reliably return JSON. extract() parses, repairs, validates and retries.

4

Scattered ASR

The speech models are separate repos. One ASRClient ties voice to the rest of the toolkit.

What you get

Everything you need to ship on N-ATLaS.

🔌 Unified backends

One client for TGI (Hugging Face Inference Endpoints), vLLM / OpenAI-compatible servers, and an offline mock for tests and CI.

🧩 Structured JSON

Turn free text into validated JSON with a tiny schema. Parsing, repair, type-coercion and retry are handled for you.

🗣️ Nigerian-language tasks

Ready helpers for translate, detect-language, classify and summarize across English, Hausa, Igbo, Yoruba and Pidgin.

🎙️ Speech-to-text

An ASR client for the N-ATLaS speech models, so voice-first apps go from microphone to structured data in one toolkit.

📊 Eval harness

Measure your integration on the real model, prove it works and catch regressions in CI with natlas eval.

🐍 Python & TypeScript

The same API in both ecosystems, so web, React Native and ML teams can all build on N-ATLaS without leaving their stack.

Quickstart

Three lines to your first call.

python
# pip install natlas-kit
from natlaskit import NatlasClient, extract

nat = NatlasClient.from_env()   # any N-ATLaS endpoint
nat.ask("Translate 'good morning' into Yoruba")
# -> "Ẹ kaaro"

extract(nat, "Sold 2 brake pads for 15k to Musa on credit", {
  "item":   {"type": "string", "required": True},
  "amount": {"type": "number", "required": True},
  "on_credit": {"type": "boolean", "default": False},
})
# -> {"item":"brake pads","amount":15000,"on_credit":true}
typescript
// npm install natlas-kit
import { NatlasClient, extract } from "natlas-kit";

const nat = NatlasClient.fromEnv();

await nat.ask("Translate 'good morning' into Hausa");

await extract(nat, "Paid 6k for fuel today", {
  category: { type: "string", required: true },
  amount:   { type: "number", required: true },
});
// -> { category: "fuel", amount: 6000 }
